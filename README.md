# Obquan Schemas (`schema.obquan.com`)

Public ontologies, RDF vocabularies, and JSON-LD contexts maintained by Obquan.

## AI Agent Registry Service (AARS) — `v1`

The AARS Ontology defines the core classes, properties, and metadata structures for describing and discovering AI agents within the Obquan registry ecosystem.
